# FirmGuard 1.0.0

- Added bounded native firmware archive extraction and optional isolated Binwalk v3 extraction.
- Added configuration rules, ELF hardening metadata, component inventory and curated offline version checks.
- Added per-file hashes, file/software/finding comparisons, persistent saved revisions and report exports.
- Replaced the interface with conventional upload, history, comparison and help pages.
- Added security/API/browser tests, generated sample releases, setup/start/test scripts and toolchain documentation.
